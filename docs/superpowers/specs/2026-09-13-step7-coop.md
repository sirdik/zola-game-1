# Krok 7: Lokální coop (druhý hráč)

Roadmapa (CLAUDE.md), bod 7: "Lokální coop: druhý hráč (WASD /
gamepad), sdílená kamera, společná zásoba."

Tento dokument řeší implementační detaily. Herní koncept je popsaný
jinde — zde se neopakuje.

## Rozsah

V tomto kroku:
- druhý hráč (`Player2`, WASD + levý Shift + F), vždy přítomný ve hře
  od začátku (žádný "join" flow)
- `CoopCamera` sleduje střed mezi hráči, přibližuje/oddaluje se podle
  jejich vzdálenosti, teleportuje tuláka zpátky ke skupině
- oprava `campfire.gd`'s počítadla hráčů v dosahu (bug objevený při
  návrhu — jeden bool by se s druhým hráčem choval špatně)
- táborákové menu je sdílené — kterýkoliv hráč ho svou akcí otevře,
  oba ho pak mohou ovládat
- `animal.gd` reaguje na nejbližšího hráče místo "prvního nalezeného"
- hráči mají odlišnou barvu, aby šli od sebe poznat na obrazovce

Mimo rozsah (pozdější kroky): gamepad (rodina nemá k testování, viz
poznámka níže), víc než 2 hráči (CLAUDE.md zmiňuje "1–4", ale tenhle
krok řeší jen druhého hráče — rozšíření na 3.–4. by vyžadovalo
zobecnit natvrdo napsané `p1_*`/`p2_*` kontroly na smyčku), rozdělení
`Game.energy` na hráče a "usnutí/probuzení jídlem" (krok 8 — dělat to
napůl teď by se muselo předělávat), síťový coop (CLAUDE.md to
explicitně vylučuje).

**Poznámka ke gamepadu:** rodina nemá gamepad k dispozici na
otestování, takže mapování os/tlačítek by šlo nastavit jen naslepo bez
možnosti ověřit, že sedí — proto zůstává mimo rozsah. Lze přidat
kdykoliv později čistě jako nová vazba v `project.godot`'s InputMap,
beze změny kódu.

## Hráč 2 a InputMap

Nové akce v `project.godot`'s `[input]` sekci, zrcadlící existující
`p1_*` (fyzické klávesy, stejný formát jako u `p1_*`):

- `p2_move_forward` = W (`KEY_W`, physical_keycode 87)
- `p2_move_back` = S (`KEY_S`, physical_keycode 83)
- `p2_move_left` = A (`KEY_A`, physical_keycode 65)
- `p2_move_right` = D (`KEY_D`, physical_keycode 68)
- `p2_jump` = levý Shift (`KEY_SHIFT`, physical_keycode 4194325)
- `p2_action` = F (`KEY_F`, physical_keycode 70)

`game/player/player.gd` už nic nepotřebuje měnit — `_action()` už
odvozuje název akce z `player_number`, přesně pro tenhle účel postavené
v kroku 1.

`game/world/Forest.tscn`: přidat `Player2` jako druhou instanci
`Player.tscn` (stejně jako `Player1`), s instance-level přepisem
`player_number = 2`. Počáteční pozice mírně vedle `Player1` (přesná
pozice se stejně přepíše `level_loader.gd`, viz níže) — na `Player1`'s
transformu zkopírovat, `x` posunout o pár desetin metru, ať se
nepřekrývají, než level_loader oba přemístí na start.

## `game/world/level_loader.gd`: start obou hráčů

Aktuální `@export var player_path: NodePath = NodePath("../Player1")`
a jeho použití v `_ready()`:

```gdscript
	if player_spawn_found:
		var player := get_node_or_null(player_path)
		if player is Node3D:
			player.global_position = player_spawn_pos + Vector3(0, 0.05, 0)
```

přesně na sobě:

```gdscript
@export var player_paths: Array[NodePath] = [NodePath("../Player1"), NodePath("../Player2")]
```

```gdscript
	if player_spawn_found:
		for i in player_paths.size():
			var player := get_node_or_null(player_paths[i])
			if player is Node3D:
				player.global_position = player_spawn_pos + Vector3(0, 0.05, 0) + Vector3(i * 1.0, 0.0, 0.0)
```

`Forest.tscn` nepřepisuje `player_path` (spoléhá na výchozí hodnotu ze
skriptu), takže přejmenování exportované proměnné nevyžaduje žádnou
úpravu scény.

## `game/camera/coop_camera.gd`: střed, zoom, teleport

Současný stav sleduje jen prvního nalezeného hráče
(`get_tree().get_nodes_in_group("players")[0]`, cachováno,
`is_instance_valid` re-lookup). Nahradit sledováním středu všech
hráčů, počítaným znovu každý snímek (žádná potřeba cachovat/ověřovat
platnost — čerstvý dotaz na skupinu to řeší samo):

```gdscript
class_name CoopCamera
extends Node3D

@export var follow_speed: float = 5.0
@export var min_spring_length: float = 7.0
@export var max_spring_length: float = 14.0
@export var max_player_spread: float = 15.0
@export var zoom_speed: float = 3.0

@onready var spring_arm: SpringArm3D = $SpringArm3D

func _process(delta: float) -> void:
	var players := _get_players()
	if players.is_empty():
		return

	var midpoint := _compute_midpoint(players)
	var move_t: float = clamp(follow_speed * delta, 0.0, 1.0)
	global_position = global_position.lerp(midpoint, move_t)

	var spread := _compute_max_spread(players, midpoint)
	_teleport_stragglers(players, midpoint, spread)

	var target_spring_length: float = clamp(min_spring_length + spread * 0.5, min_spring_length, max_spring_length)
	var zoom_t: float = clamp(zoom_speed * delta, 0.0, 1.0)
	spring_arm.spring_length = lerp(spring_arm.spring_length, target_spring_length, zoom_t)

func _get_players() -> Array[Node3D]:
	var result: Array[Node3D] = []
	for node in get_tree().get_nodes_in_group("players"):
		if node is Node3D:
			result.append(node)
	return result

func _compute_midpoint(players: Array[Node3D]) -> Vector3:
	var sum := Vector3.ZERO
	for p in players:
		sum += p.global_position
	return sum / players.size()

func _compute_max_spread(players: Array[Node3D], midpoint: Vector3) -> float:
	var max_dist := 0.0
	for p in players:
		max_dist = max(max_dist, p.global_position.distance_to(midpoint))
	return max_dist

func _teleport_stragglers(players: Array[Node3D], midpoint: Vector3, spread: float) -> void:
	if spread <= max_player_spread or players.size() < 2:
		return
	for p in players:
		var to_player := p.global_position - midpoint
		to_player.y = 0.0
		if to_player.length() > max_player_spread:
			p.global_position = midpoint + to_player.normalized() * (max_player_spread * 0.6) + Vector3(0, 0.05, 0)
```

Poznámky:
- `spring_arm.spring_length` se mění plynule (vlastní `zoom_t` lerp),
  ne skokem — stejný "plynulé přiblížení" pocit jako existující
  `follow_speed`.
- Hodnoty (`min/max_spring_length`, `max_player_spread`, násobek
  `0.5` pro zoom podle rozestupu) jsou orientační, doladíme podle
  hraní ve dvou.
- Když existuje jen jeden hráč (`players.size() == 1`), `spread` vyjde
  0 a `spring_length` se ustálí na `min_spring_length` — chování pro
  sólo hraní se nemění (except: teleport logika se přeskočí díky
  `players.size() < 2` guard).
- Teleport cílí na `max_player_spread * 0.6` od středu, ve směru, kde
  hráč byl — nehodí ho přesně na druhého hráče ani přesně na hranici.

## `game/cooking/campfire.gd`: oprava počítadla + sdílené menu

**Bug objevený při návrhu:** `_player_in_range: bool` je jeden
příznak. Se dvěma hráči: pokud jsou u táboráku oba a jeden odejde,
`_on_body_exited` nastaví `_player_in_range = false` a zavře menu i
tomu, kdo pořád stojí u ohně. Oprava — počítadlo místo boolu, HUD se
notifikuje jen na přechodu 0↔1+:

```gdscript
extends Area3D

var _players_in_range: int = 0
var _hud: Node = null

func _ready() -> void:
	body_entered.connect(_on_body_entered)
	body_exited.connect(_on_body_exited)
	call_deferred("_find_hud")

func _find_hud() -> void:
	var huds := get_tree().get_nodes_in_group("hud")
	if huds.size() > 0:
		_hud = huds[0]
		if _players_in_range > 0:
			_hud.set_near_campfire(true)

func _on_body_entered(body: Node3D) -> void:
	if body.is_in_group("players"):
		_players_in_range += 1
		if _hud != null and _players_in_range == 1:
			_hud.set_near_campfire(true)

func _on_body_exited(body: Node3D) -> void:
	if body.is_in_group("players"):
		_players_in_range = max(0, _players_in_range - 1)
		if _hud != null and _players_in_range == 0:
			_hud.set_near_campfire(false)

func _process(_delta: float) -> void:
	if _hud == null:
		_find_hud()
```

## `game/ui/hud.gd`: menu ovládá kterýkoliv hráč

Menu je společné rozhodnutí týmu — kterýkoliv hráč ho svou akcí otevře,
a dokud je otevřené, oba mohou svými klávesami procházet/potvrzovat.
Nahradit všech 6 natvrdo napsaných `p1_*` kontrol v `_process()`
dvojicí OR (`p1_*` nebo `p2_*`):

Současné (v `_process()`):
```gdscript
func _process(_delta: float) -> void:
	if eat_menu.visible:
		if Input.is_action_just_pressed("p1_jump"):
			close_eat_menu()
			return
		if _eat_menu_entries.is_empty():
			if Input.is_action_just_pressed("p1_action"):
				close_eat_menu()
			return
		if Input.is_action_just_pressed("p1_move_back"):
			_eat_menu_selected = (_eat_menu_selected + 1) % _eat_menu_entries.size()
			_update_eat_menu_highlight()
		elif Input.is_action_just_pressed("p1_move_forward"):
			_eat_menu_selected = (_eat_menu_selected - 1 + _eat_menu_entries.size()) % _eat_menu_entries.size()
			_update_eat_menu_highlight()
		elif Input.is_action_just_pressed("p1_action"):
			var entry: Dictionary = _eat_menu_entries[_eat_menu_selected]
			if entry["kind"] == "raw":
				var id: String = entry["id"]
				if Game.try_consume(id):
					Game.restore(Items.get_by_id(id)["energy_raw"])
				close_eat_menu()
			elif entry["craftable"]:
				var recipe_data := Recipes.get_by_id(entry["id"])
				Game.try_cook(recipe_data["ingredients"], recipe_data["energy_cooked"])
				close_eat_menu()
	elif _near_campfire and Input.is_action_just_pressed("p1_action"):
		open_eat_menu()
```

Nová verze — přidat dvě malé pomocné funkce a nahradit každou z 6
kontrol jejich voláním:

```gdscript
func _any_jump_pressed() -> bool:
	return Input.is_action_just_pressed("p1_jump") or Input.is_action_just_pressed("p2_jump")

func _any_action_pressed() -> bool:
	return Input.is_action_just_pressed("p1_action") or Input.is_action_just_pressed("p2_action")

func _any_menu_next_pressed() -> bool:
	return Input.is_action_just_pressed("p1_move_back") or Input.is_action_just_pressed("p2_move_back")

func _any_menu_prev_pressed() -> bool:
	return Input.is_action_just_pressed("p1_move_forward") or Input.is_action_just_pressed("p2_move_forward")

func _process(_delta: float) -> void:
	if eat_menu.visible:
		if _any_jump_pressed():
			close_eat_menu()
			return
		if _eat_menu_entries.is_empty():
			if _any_action_pressed():
				close_eat_menu()
			return
		if _any_menu_next_pressed():
			_eat_menu_selected = (_eat_menu_selected + 1) % _eat_menu_entries.size()
			_update_eat_menu_highlight()
		elif _any_menu_prev_pressed():
			_eat_menu_selected = (_eat_menu_selected - 1 + _eat_menu_entries.size()) % _eat_menu_entries.size()
			_update_eat_menu_highlight()
		elif _any_action_pressed():
			var entry: Dictionary = _eat_menu_entries[_eat_menu_selected]
			if entry["kind"] == "raw":
				var id: String = entry["id"]
				if Game.try_consume(id):
					Game.restore(Items.get_by_id(id)["energy_raw"])
				close_eat_menu()
			elif entry["craftable"]:
				var recipe_data := Recipes.get_by_id(entry["id"])
				Game.try_cook(recipe_data["ingredients"], recipe_data["energy_cooked"])
				close_eat_menu()
	elif _near_campfire and _any_action_pressed():
		open_eat_menu()
```

Poznámka: `Game.ui_blocking = true` (nastaveno v `open_eat_menu()`,
beze změny) zmrazí pohyb **obou** hráčů, ne jen toho, kdo menu otevřel
— `player.gd`'s `Game.ui_blocking` čtení je nezávislé na
`player_number`. To je záměr: rozhodování co se bude vařit je
společná pauza pro oba, ne akce jen jednoho, zatímco druhý pořád běhá
po lese.

## `game/animals/animal.gd`: nejbližší hráč

Nahradit "první nalezený, cachovaný" hráč hledáním nejbližšího každý
snímek. Přidat typovaný přístup k `Player`, ať jde bezpečně číst
`player_number` (bez `class_name`, viz konvence projektu):

```gdscript
const PlayerScript = preload("res://game/player/player.gd")
```

Změnit `var _player: Node3D = null` na:
```gdscript
var _player: PlayerScript = null
```

V `_physics_process`, nahradit:
```gdscript
	if _player == null or not is_instance_valid(_player):
		_player = get_tree().get_first_node_in_group("players")
```
za volání nové funkce, provedené každý snímek (ne jen když je `null`):
```gdscript
	_update_nearest_player()
```

Nová funkce (umístit vedle `_distance_to_player`):
```gdscript
func _update_nearest_player() -> void:
	var nearest: PlayerScript = null
	var nearest_dist := INF
	for node in get_tree().get_nodes_in_group("players"):
		if node is PlayerScript:
			var dist: float = global_position.distance_to(node.global_position)
			if dist < nearest_dist:
				nearest_dist = dist
				nearest = node
	_player = nearest
```

`_check_aggro_or_notice`, `_process_look`, `_process_chase`, `scare()`
zůstávají beze změny — pracují s `_player`, ať je to kdokoliv aktuálně
nejbližší, přesně jako doteď.

**Akce (hlazení, klakson) patří konkrétnímu nejbližšímu hráči, ne
natvrdo `p1_action`.** Přidat pomocnou funkci a použít ji na obou
místech, kde se dřív kontrolovalo `Input.is_action_just_pressed("p1_action")`:

```gdscript
func _player_action(action_name: String) -> String:
	return "p%d_%s" % [_player.player_number, action_name]
```

V `_process_look`:
```gdscript
	if _distance_to_player() <= pet_radius and _pet_cooldown <= 0.0 and not Game.ui_blocking and Input.is_action_just_pressed(_player_action("action")):
```

V `_check_horn_use`:
```gdscript
	if _distance_to_player() <= horn_radius and Game.get_count("horn") > 0 and not Game.ui_blocking and Input.is_action_just_pressed(_player_action("action")):
```

Bez tohohle by hráč 1 mohl (třeba omylem) pohladit zvíře, které je ve
skutečnosti blízko hráče 2, jen tím, že zmáčkne svoji vlastní akční
klávesu odkudkoliv na mapě — protože `Input.is_action_just_pressed`
neví nic o vzdálenosti, jen o tom, jestli je akce zrovna stisknutá.

## Ověření

- `godot --headless --path . --quit` po každé významnější změně.
- Ruční hraní ve dvou (nebo jeden hráč ovládající obě sady kláves
  postupně, pro rychlé ověření): oba hráči se hýbou nezávisle
  (šipky vs. WASD), mají různou barvu, kamera drží střed a
  přibližuje/oddaluje se podle toho, jak daleko od sebe jsou, vzdálený
  hráč se teleportuje zpátky. U táboráku: menu otevře kterýkoliv
  hráč, oba ho mohou ovládat, zavření/otevření funguje správně i když
  jeden hráč odejde a druhý zůstane. Zvíře si všimne/uteče/zaútočí
  podle toho, kdo je zrovna blíž, a hlazení/klakson reaguje na akční
  klávesu toho konkrétního hráče.
